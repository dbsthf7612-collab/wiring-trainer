# 컨트롤박스 배선 연습

시퀀스 도면을 보고 가상 판넬에 배선한 뒤, 전원을 넣어 동작을 확인하는 연습 게임입니다.
기초(램프 · 자기유지)부터 중급(인터록 · 리밋 · 타이머 · 플리커), 전기기능사 실기 수준(3상 기동 · 정역 · Y-Δ)까지 12단계.

- 휴대폰에서도 동작합니다. 브라우저 메뉴의 "홈 화면에 추가"로 앱처럼 설치할 수 있습니다.
- 아이콘은 `python3 tools/make_icons.py`로 다시 만들 수 있습니다.
- 진행 상황(별, 배선)은 브라우저에 저장됩니다.

## 수정하는 법
1. `app.html`을 고칩니다.
2. `node build.js`로 `index.html`을 다시 만듭니다.
3. 커밋하고 푸시하면 GitHub Pages에 반영됩니다.
